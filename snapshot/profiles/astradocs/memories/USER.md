Пользователю важна полная взаимная согласованность синтетических логистических данных: заявки на отправку, спецификации, инвойсы и другие документы должны связываться между собой и быть пригодными для последующего динамического дашборда.
§
В «Плане логиста» пользователь предпочитает расчёт по существующим заказам и партиям, без выдуманных комплектов. Приоритет — срок доставки; объединение партий допустимо только если ожидание не создаёт опоздание. Нужны объяснения дат и раскрываемые детали рекомендаций.
§
Пользователю нужен встроенный гайд по дашборду для людей без технических знаний: каждое действие описывается пошагово с явным ожидаемым результатом.
